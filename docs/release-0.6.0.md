# 0.6.0

面板重做。设置框与子 Agent 列表改为明确的层级结构：标题 / 内容 / 底栏三段，内容按「外观」「当前会话」分组，开关改为轨道式控件并把说明放在各自条目下，去掉原先成段的解释文字。列表行改为两行式（标题 + 状态），空态给出可行动的说明。

面板配色不再写死浅色，改为读取宿主 token（`--dsw-alias-bg-overlay`、`--dsw-alias-border-l2`、`--dsw-alias-label-primary|secondary|tertiary`、`--dsw-alias-bg-mask-1`），并以 `prefers-color-scheme` 与 `[data-ds-dark-theme]` 双通道兜底。深色主题或第三方皮肤下，面板与遮罩不再与界面冲突。字体改为继承宿主。

补上动效规范里两条尚未实现的约定：超过 3 个会话同时流动时统一降噪，避免侧边栏变成彩虹；消息飞行期间同会话小球的冒泡降速让位，保证发射类动效完整播放（`ld-emitting` 此前只被移除、从未被添加，本次接上）。

小球颜色（macOS 红黄绿实心）、无玻璃层、边缘流光的形状与路径均未改动。
