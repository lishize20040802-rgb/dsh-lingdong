# 灵动 · dsh-lingdong 0.5.4

[简体中文](README.md) · [English](README.en.md)

在官方 DeepSeek Harness Desktop 0.1.7-rc.2 界面上增加小幅视觉增强。保持官方布局、字体、按钮尺寸、输入组件、消息内容、附件和发送逻辑。

## 新一代交互

- **顶部子 Agent**：官方背景上的无边框点击区域，始终并排显示红黄绿三个纯色球；Agent 随机分配颜色，同一 Agent 保持颜色。三个大球始终保持完整圆形，只有工作中的球向上冒出同色小泡；双球相互环绕，三球交错缠绕，结束时沿弧线回到原位。子 Agent 直接在顶部出现，不从对话区飞来。
- **真实身份与状态**：只读取官方 subagentCatalog / 会话状态。不订阅、不显示后台任务。超过 3 个保留前 3 个真实 Agent 的球，点击胶囊查看全量名单。颜色不代表运行结果。
- **文字完整收拢与展开**：在用户输入/点击/回车时只读保存输入的实际 DOM 样式、位置、换行、大小和滚动位置。发送后对整段文字的视觉副本做连续缩放，从原位收拢成彩色流光球，飞到真实消息气泡，再展开为官方气泡的视觉副本。默认 320 ms 收拢、420 ms 飞行、360 ms 展开，阶段交叠，总计约 0.98 s。
- **真实落点**：每帧读取气泡几何，适应布局变化、滚动和临时消息确认替换。目标是官方文字气泡，不含附件或复制按钮。文字不截取，不逐字散开，也不把真实消息挪来挪去。
- **会话边缘光晕**：几团形状不同的蓝紫粉彩光沿会话按钮四周流动，向按钮内侧逐渐消散；各会话错开节奏，没有固定描边。光晕作为按钮自身的伪元素，官方将会话移到顶部时它立即一起移动；不添加按钮子元素，不改背景、尺寸和文字。
- **保留轻量阅读动效**：新流式段落淡入，结构化内容整块出现；历史内容不重播。

## 安装与设置

在官方桌面应用的「插件 → 安装插件 → 本地目录」选择完整的 dsh-lingdong 文件夹；或者安装同版本 tgz 包。包含预构建 lib，无需构建。当前仅兼容官方 0.1.7-rc.2；升级宿主后需重新核验。

点击右上角三个小球 →「灵动动效设置」，可切换启用动效和背景氛围。继承旧版的已保存开关。无子 Agent 时仍显示三个空闲小球。

停用/卸载会清理样式、按钮光晕、监听器、动画和消息隐藏状态。发送失败、切换会话、页面隐藏或目标离开可见区域会立即恢复真实消息。遵循系统减少动态效果和高对比度设置。

## 边界

无模型调用，无聊天记录读取，无数据上传。插件只读官方前端状态，不接管输入事件、不修改消息内容。

消息气泡选择器已与本机官方 0.1.7-rc.2 的 UserStyleBubble 核对。若未匹配真实输入快照或气泡（如程序化发送、仅附件或未知宿主结构），安全降级为短暂静态描边，避免虚构文字位置。侧边栏光晕绑定在按钮上，只在状态或按钮节点变化时更新标记，不按流式字符重绘。

当前仍是 DOM 视觉增强插件，宿主升级可能改变选择器；不承诺未知版本兼容。四个以上 Agent 的颜色会复用，名称和列表区分身份。

## 开发

```sh
npm ci --ignore-scripts --legacy-peer-deps
npm run check
npm run test:browser
node scripts/build.mjs --check
```

离线构建可用 DSH_ESBUILD_PATH 指向 esbuild/lib/main.js；浏览器测试用 DSH_TEST_MODULES 指向包含 esbuild、react、react-dom、playwright-core 的目录，DSH_BROWSER 指向 Chromium，DSH_TEST_OUTPUT 指定结果目录。

发布验证见 docs/verification.md。测试不发送真实聊天消息。
