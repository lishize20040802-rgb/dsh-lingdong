# 灵动 · DSH 桌面端插件

为 **官方 DeepSeek Harness Desktop 0.1.7-rc.2** 的主对话界面增加克制的流动动效。按提供的《动效方案》《动效规范》实现，使用官方 Cordis 插件、bundle patch、客户端模块协议与增量插槽。

## 桌面端安装

推荐：在 **DeepSeek Harness 桌面应用 → 插件 → 安装插件** 中输入：

```text
github:lishize20040802-rgb/dsh-lingdong#v0.3.0
```

**如需不可漂移的安装规格，请复制 [v0.3.0 发布页](https://github.com/lishize20040802-rgb/dsh-lingdong/releases/tag/v0.3.0) 中的完整 commit 地址**。标签方便识别版本；完整提交比浮动分支或标签更严格。

也可输入仓库地址 `https://github.com/lishize20040802-rgb/dsh-lingdong`。仓库包含构建产物，安装无需在本地编译。

本地目录安装：

1. 将完整的 `dsh-lingdong` 文件夹放到一个固定位置。目录中必须包含 `package.json`、`cordis.patch.yml` 和 `lib/`。交付目录已经构建好，不需要先安装 Node.js 或运行构建命令。
2. 在 **DeepSeek Harness 桌面应用**的侧边栏打开 **插件 → 安装插件 → 本地目录**。
3. 输入这个 `dsh-lingdong` 文件夹的绝对路径，安装并启用。
4. 打开一个对话。顶部出现 `◌` 设置按钮；发送消息、流式回复和运行子 agent 时可观察动效。

停用或卸载同样在桌面应用的插件页面完成。插件移除时会释放观察器、定时器、动画和样式，恢复官方 UI。

**不要使用 `dsh plugin --profile web` 安装本插件到桌面端，也不要使用 `--profile desktop`。** 当前官方 CLI 明确拒绝直接操作 Electron 专属的 `desktop` profile。桌面应用的插件管理器负责调用内置 pnpm、更新自己的插件清单并同步前端。

GitHub 上的源码和下载包不会自动修改桌面应用，需按上述步骤安装。

## 已实现

| 规则 | 行为 |
|---|---|
| D1 侧边栏 | 整条会话按钮显示流动彩色背景，文字保持官方原色。当前会话为蓝紫／粉色层（14–17 秒），运行任务为青绿／暖金色层（9–12 秒）；同时选中并运行时保留选中配色、加快第二色层。其他空闲会话静态。 |
| D2 发送 | 输入文字的视觉副本收拢成球，直接缓慢飞往聊天区对应消息位置，然后展开成原生消息。不会飞向顶部。消息正常提交，只在飞行期间暂时隐藏目标的视觉显示，保持布局与可访问文本；取消、失败、切换会话均恢复。临时消息替换为正式消息时继续衔接。 |
| D3 自然语言 | 新出现的流式段落模糊到清晰；已有段落追加字符不会反复重新模糊。打开历史不重播。 |
| D4 结构化内容 | 新代码块、列表、表格整块淡入并轻微上浮，不重写 Markdown 或打散代码节点。 |
| D5 生成标记 | 流式内容末尾使用与顶部细线同色的柔光点；流式结束后消失。 |
| D6 任务球位置 | 新任务球从当前可见的 AI 回复区域发出，沿独立路径进入顶部 actions 插槽。使用插件自己的裁剪浮层，避免被顶部小球容器裁断。打开历史任务不重播；无可见 AI 来源时直接展示状态，不虚构发射位置。 |
| D7 任务球状态 | 持续子代理、一次性后台子代理、后台进程均有小球。运行时玻璃珠轻微起伏、内部色彩游动与冒泡；结束后消散，提示保留真实完成／失败／停止状态。历史结束记录不重播。 |
| D8 任务球交互 | 悬浮或键盘聚焦显示任务名称和真实运行状态，不打开迷你线程。 |
| D9 背景 | 固定 24 秒氛围周期，不随任务数量变化。 |

原生附件、消息内容、代码复制、链接、发送/停止、排队、中文输入法均由 DSH 原组件负责。本插件不接管输入事件，不添加模型工具或模型请求；任务列表通过官方 `jobs.watchRows` 共享订阅获取，不读取任务输出流，不读取磁盘聊天记录，不上传数据。

## 设置与默认值

顶部 `◌` 按钮可以切换「启用动效」「背景氛围」「超过 4 个小球时折叠」。设置仅保存在此桌面渲染器的 localStorage，存储不可用时仍可使用。

以下是**实现默认值，并非原始对话已确认的决定**：

- 发射一次只播放一个，最多额外保留 3 个装饰动画；超出的真实消息照常发送，仅省略装饰。发送与顶部 AI 任务入场彼此独立。
- 超过 4 个小球时显示 `+N`，可展开全部状态球，不展开子线程；可在设置中关闭聚合。隐藏的完成球也会清理。
- 暂不加入「结果光尾」。窄桌面窗口采用顶部聚合和限高换行，不增加侧滑抽屉。
- 用户消息：收拢 580ms、直达飞行 1850ms、展开 900ms，合计约 3.33 秒。AI 任务球入场 2200ms。升级保留旧版开关，采用新的时序。

遵循 `prefers-reduced-motion`：移除运动、冒泡和模糊，提交改为短暂静态描边，状态仍然可读。支持系统高对比度模式；颜色取自 DSH 的主题变量，适配桌面深浅主题。

## 兼容范围与边界

- 已核对本机官方 Desktop `0.1.7-rc.2`，构建提交 `c1275515b6b97551ec358c926c479ab750c687c0`。包的 `engines.dsh` 与 DSH peer 版本都限定为此版本，升级后应重新验证。
- Desktop 使用 Electron 承载官方前端，所以 manifest 的 `dsh.client.platform` 正确值仍是 **`web`**；这不表示它要安装到 Web profile。见[官方 Desktop 文档](https://github.com/deepseek-ai/deepseek-harness/blob/master/apps/desktop/README.md)。
- 官方尚无段落动画装饰插槽。本插件通过现有插槽挂载观察器，再对 `data-conversation-content`、`data-chat-flow-kind`、`data-streaming` 和侧边栏行结构做限定范围的视觉增强。这些 DOM 结构不是永久兼容承诺。命中不到时跳过装饰，不替换宿主内容。
- 排队状态和百分比进度不是当前目录提供的完整事实。提示显示「排队 / 等待状态同步」或「当前未运行」，运行时显示「工作中」，**不伪造百分比**。错误、取消、暂停不冒充正常完成，官方原有错误提示保留。
- 小球是装饰性视觉副本，发送成功仍由 DSH 原生状态决定。没有找到新的可见目标消息时跳过发送动效，避免错误隐藏历史消息。飞行时不删除、重排或改写原生消息。
- 核验覆盖官方协议与真实 Chromium 下的 DOM 测试夹具，尚未在你的正在运行的 Electron 会话中安装联调。

## 开发与验证

```sh
npm ci --ignore-scripts --legacy-peer-deps
npm run check
node scripts/build.mjs --check
npm run test:browser
```

浏览器测试默认寻找 Windows Edge；其他安装位置可设置 `DSH_BROWSER` 为 Chromium 可执行文件。测试使用隔离的临时浏览器环境，不读取现有桌面会话。官方契约测试需先设置 `DSH_REFERENCE_ROOT` 为已安装的 `@deepseek-ai` 包目录，再运行 `npm run test:official`。

离线开发可通过 `DSH_ESBUILD_PATH` 指定已有 esbuild 的 `lib/main.js`，通过 `DSH_TEST_MODULES` 指定含 esbuild、react、react-dom、playwright-core 的开发依赖目录。`DSH_TEST_OUTPUT` 可指定测试结果目录。

安装包也包含源码、构建脚本与测试；`node scripts/build.mjs --check` 比较源代码构建与已发货字节。

源码入口：`src/index.js`（宿主发现）、`src/client.js`（插槽与状态）、`src/model.js`（状态规则）、`src/motion.js`（DOM 适配和生命周期）、`src/style.css`（主题与动效）。

详细核验见 [验证报告](docs/verification.md)，接口出处见 [官方规范对照](docs/official-contract.md)。
